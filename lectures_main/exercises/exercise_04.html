path preparation

Parse \(N\) complete poses, normalize every quaternion, confirm its component order, and store \(T_k=[R_k,p_k]\) for \(k=0,\ldots,N-1\). Inspect corners and pose continuity before solving IK.

Determine \(N\) from the file; the current course CSV has \(N=500\) data rows. If you resample, interpolate translation in \(\mathbb R^3\), use sign-consistent quaternion slerp for orientation, and document the new \(N\). A finite path grid can miss a narrow infeasible interval.

Construct the redundancy grid

Use exactly 175 negative and 175 positive angles

\[ \Lambda=\{\lambda^-_1,\ldots,\lambda^-_{175},\lambda^+_1,\ldots,\lambda^+_{175}\}, \quad \lambda^-_i<0<\lambda^+_i, \quad |\Lambda|=350 \]

Sampling contract

  • Use the negative and positive bounds defined in the assignment data.
  • Sort the final vector monotonically and record units.
  • Do not silently add \(0\): zero is not in the 350-sample baseline.
  • If the assignment data explicitly requests a zero row, add it and report \(N_\lambda=351\).
Choose the stated redundancy coordinate consistently—e.g. \(\lambda=q_3\). A coordinate is a chart of the self-motion family, not a claim that the family is globally one-to-one.

Evaluate all branches

Every grid cell requests up to eight labelled branch candidates

\[q_{b,k,j}=\operatorname{IK}_b(T_k;\lambda_j),\qquad b=1,\ldots,8,\quad k=0,\ldots,N-1,\quad j=0,\ldots,349\]
Joint tensor\(Q\in\mathbb R^{8\times N\times350\times7}\). For the current \(N=500\) file: 9,800,000 joint scalars.
Feasibility mask\(V\in\{0,1\}^{8\times N\times350}\). For \(N=500\): 1,400,000 branch/sample/angle decisions.
One branch image350 redundancy rows × \(N\) path columns. Produce eight comparable maps.

Preserve eight slots

Track all eight analytical branch labels even when a candidate is absent or non-real. Array order alone is not a stable branch label.

Represent failure

Store invalid joint vectors as missing values plus a reason code; never replace them with zeros or a neighbouring solution.

Validate and classify each cell

Feasibility is the intersection of several tests

Pose closure

Require finite real joints and verify position/orientation FK residuals against \(T_k\).

Joint limits

Test the physical iiwa limits after resolving angle periodicity consistently.

Regularity

Record both full-Jacobian \(\sigma_{\min}\) and any fixed-\(\lambda\) reduced determinant used by the analytical chart.

Continuity and collision

Run the course collision checker when available. Store wrapped \(\Delta q\) tests on transitions between chosen neighbouring cells.

\[V^{cell}_{b,k,j}=V_{FK}\land V_{limit}\land V_{regular}\land V_{collision},\qquad E_{b,(k,j)\to(k+1,j')}=V^{cell}_{b,k,j}V^{cell}_{b,k+1,j'}\,\mathbf 1[\|\operatorname{wrap}(\Delta q)\|\le\tau_q]\]
Continuity is an edge property: use \(j'=j\) for a constant-\(\lambda\) path, or state which \(j\to j'\) moves are allowed for a varying schedule. A reduced-chart fold and full \(6\times7\) rank loss are different events; report them separately.

Build the eight feasibility maps

Plot redundancy angle against path progress—and keep the reason for every gap

Required plot

  • Horizontal axis: path sample \(k=0,\ldots,N-1\).
  • Vertical axis: the 350 ordered values of \(\lambda\).
  • One panel per branch with identical axes and colour rules.
  • Distinguish limit, singular/chart, discontinuity, collision, and IK-loss failures.

Questions to answer

  • Does any constant-\(\lambda\) row remain feasible for the complete path?
  • Is there a connected corridor for a varying schedule \(\lambda(k)\)?
  • Which branch has the widest margin to limits and singularities?
  • Where do branches appear, merge, or terminate?
A continuous-looking pixel corridor is a candidate schedule. Recover its joint sequence and revalidate the actual transitions before calling it a path.

Path-placement experiment

Translate and rotate the command—not the robot meshes

\[T'_k=T_\Delta T_k,\qquad p'_k=R_\Delta p_k+t_\Delta,\qquad R'_k=R_\Delta R_k\]

Left multiplication places the complete path in a new base-frame pose. Record \(T_\Delta\) for every trial so the experiment is reproducible.

Compare placements quantitatively

  • Feasible-cell fraction per branch.
  • Number and width of complete-path corridors.
  • Minimum joint-limit, singularity, and clearance margins.
  • Best candidate’s total wrapped joint travel.
Path placement is not mesh placement. \(T_\Delta\) changes desired workspace poses and therefore IK feasibility. Editing a URDF visual origin changes only how an STL is drawn on its link.
