ENG-654 · Lecture 07

Workspace Path Planning

Follow a supplied workspace path or trajectory with a feasible joint motion

The desired motion is supplied by a precomputed trajectory or a real-time policy. We study planning methods for noncuspidal and cuspidal robots.

Our starting assumption

We study workspace path planning with a given path or trajectory

Assume that a desired workspace path or trajectory has been given to the robot to follow. It can come from either source below.

1 · Precomputed trajectories

The desired motion is calculated in advance and supplied as a sequence of workspace targets, with timing when a trajectory is specified.

The complete command is available for analysis before execution.

2 · Real-time policies

A policy uses current observations to provide the next desired workspace pose or motion command while the robot moves.

Only the current command or a short future horizon may be available.

A path specifies where to move; a trajectory also specifies when. Our task is to find a continuous joint motion that follows the supplied command while checking singularities and joint limits.

“Lift” means the continuous joint trajectory \(\mathbf q(s)\) that realizes the chosen task-space curve: \(f(\mathbf q(s))=\mathbf x_d(s)\). It is a mathematical mapping, not an upward motion. The same Cartesian curve can have several such joint paths, each with a different outcome.

Part 1 · Numerical and analytical path planning

Build a joint path using local continuation or complete inverse solutions

Numerical continuation

\[{}^0\mathcal V_t=\begin{bmatrix}{}^0\dot{\mathbf p}_t\\{}^0\boldsymbol\omega_t\end{bmatrix}={}^0J_t(\mathbf q)\dot{\mathbf q}\]

Solve the velocity equation near the current configuration. Predict the next joint state, correct its FK error, and validate that step.

One initial IK selects one local trajectory.

Analytical or algebraic IK

\[\mathcal Q_k=f^{-1}({}^0T_{t,d}(t_k))\]

Enumerate every real solution at each target pose using closed-form expressions or an algebraic root solver. Connect adjacent solutions continuously.

Enumeration reveals candidates; connectivity and constraints determine feasible paths.

For a 6R robot, “\(\dot{\mathbf x}=J\dot{\mathbf q}\)” uses the geometric velocity \([\dot{\mathbf p};\boldsymbol\omega]\). An Euler-angle derivative needs its representation-dependent angular mapping.

Part 1 · Numerical safeguards

Local safeguards detect failure; they cannot select a globally viable start

Step size

Large Cartesian steps invalidate the local linear model and can jump to another basin.

Near singularity

Stop when the full Jacobian becomes singular or ill-conditioned. Damping can moderate a numerical step, but cannot restore a missing task direction.

Joint limits

A regular branch may still hit a physical joint stop. Global comparison can select a different initial IK that completes the path; it does not remove the stop.

\[\|\dot{\mathbf q}\|\ \text{can grow while}\ \|\dot{\mathbf x}\|\ \text{stays modest as}\ \sigma_{\min}(J)\to0.\]

Part 2 · Hybrid planning · enumerate once, then continue

Start with all analytical IKs, then follow each with the Jacobian

\[\begin{bmatrix}{}^0\mathbf v_6\\{}^0\boldsymbol\omega_6\end{bmatrix}={}^0J_6(\mathbf q)\dot{\mathbf q}\]
\[{}^0J_6(\mathbf q_k)\Delta\mathbf q=\begin{bmatrix}{}^0\mathbf p_{6,d}-{}^0\mathbf p_6\\\operatorname{Log}(R_dR^\top)^\vee\end{bmatrix}\]
\[|\det {}^0J_6|<\varepsilon\quad\Longrightarrow\quad\text{stop this continuation}\]

Evaluate the twist at the tool. For this robot, the tool origin is \(O_6\). With \({}^0\mathbf r_{56}={}^0\mathbf p_6-{}^0\mathbf p_5\), shift the wrist Jacobian to the tool: \({}^0J_6=\begin{bmatrix}I&-[{}^0\mathbf r_{56}]_\times\\0&I\end{bmatrix}{}^0J_5\). Here \([\mathbf r]_\times\mathbf a=\mathbf r\times\mathbf a\), and \(\det{}^0J_6=\det{}^0J_5\).

Here \(R={}^0R_{\mathrm{tool}}\) and \(R_d={}^0R_{\mathrm{tool},d}\) are the current and desired tool orientations. \(\operatorname{Log}(R_dR^\top)^\vee\) is their axis–angle error vector in the world frame.

1

Solve all IKs analytically at the first pose. Classify S, E, W and retain starts inside the joint limits.

2

For each start, compute \({}^0J_6\dot{\mathbf q}=[{}^0\dot{\mathbf p}_{6,d};{}^0\boldsymbol\omega_d]\), then predict \(\mathbf q_{k+1}\approx\mathbf q_k+\Delta t\dot{\mathbf q}_k\).

3

Correct the predicted pose by Newton iterations using the displayed position and orientation error.

4

Check singularities, position limits, and joint-speed demands along the whole path. Slow down for a speed limit; choose another branch when a joint stop blocks the path.

Part 4 · Global path analysis

Turn inverse solutions along the path into a connectivity graph

Nodes · all IKs at each sample

\[\mathcal Q_k=\{\mathbf q_k^{(1)},\mathbf q_k^{(2)},\ldots\}\]

Each task pose is a layer. Retain its real inverse solutions and mark those outside joint limits.

Edges · verified continuations

Connect adjacent layers only when the joint motion is continuous and satisfies the required limits and singularity margin. Equal determinant sign alone does not establish connectivity.

Search · an entire joint path

Search from the first layer to the last. If no chain is found, refine uncertain connections before declaring the command infeasible. For a closed task loop, compare final and initial configurations and test another lap.

For a cuspidal 6R robot, local S/E/W-style labels do not provide a complete global description. Check the actual joint connections. Regular closed loops, solution-changing loops, and failed continuations can occur on the same robot.

Graph-planning approach: Elias & Wen (2025), Section 4; authors’ implementation.

Part 4 · Put the four parts together

Global analysis connects solutions before choosing the joint trajectory

1

Receive the workspace path or trajectory from a precomputed command or a real-time policy.

2

Enumerate candidate IKs and connect continuous joint trajectories over the available path or planning horizon.

3

Track branch identity, singularity distance, joint limits, and collisions.

4

For closed task loops, test joint-space closure and repeatability explicitly.

Hybrid conclusion: enumeration supplies the candidate IKs; continuation connects them locally; comparing full trajectories reveals limits, singularities, endpoint changes, and repeatability. For a known path, global analysis can choose a viable start or identify an infeasible command. With a real-time policy, feasibility must be reassessed as new commands arrive. The demonstrations check kinematics and joint limits; collision and dynamics checks are additional planning stages. Lecture 08 adds redundancy.
