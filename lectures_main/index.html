ENG-654

Kinematics-Grounded Motion Planning for Robots

From reading a robot model to planning a globally informed motion.

The course follows one question: how can a workspace path become a valid joint-space motion? We first make the mechanism readable, then invert its kinematics, locate singularities, understand how inverse solutions connect, and finally use that global structure in motion planning.
