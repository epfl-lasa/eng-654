KINEMATIC BUILDING BLOCKS

Build a motion, one block at a time.

  1. Add a block. Drag it onto the canvas or click it in the toolbar.
  2. Edit its parameters. Select a block or right-click → Edit. Enter numbers, Greek names such as theta_2 or alpha_2, LaTeX such as \phi_{12}, or expressions such as pi/2 and 2*a. Inputs display mathematical notation when you finish editing.
  3. Connect motions. Drag the right output port to another block’s left input port. You can also click one port, then the other. Each input port accepts one connection; an output can feed several blocks. Add vectors, Subtract vectors, Cross product, Stack columns, and Stack rows have separately labelled inputs. You can also choose their sources in the inspector.
  4. Read the result. The lower panel shows the selected block’s accumulated output. Enter either symbols or numbers directly in the block inputs. Each block owns its symbols; repeated names in another block are renamed automatically.
  5. Take the code with you. Right-click → Python code to inspect, copy, or download the commented functions and composition.

Order matters

A → B computes A B using column vectors. When this product acts on a point, the rightmost matrix acts first. Connecting a rotation and translation embeds both in 4 × 4 homogeneous matrices. A D–H chain is Rz(θ) · Tz(d) · Tx(a) · Rx(α).

Use Ctrl+Shift+M (⌘+Shift+M on macOS) to minimize selected blocks into squares or restore their full size. Connected input blocks tuck inside Add, Subtract, and other operations beside their input port, and move with the operation. Restoring the block brings it back to its original position. Their ports stay available for connections. The same action is available in each block’s menu.

Once Add, Subtract, Scalar multiplier, Cross product, Stack columns, or Stack rows has valid inputs, the operation and its input blocks are replaced by a single editable vector or matrix containing the result. Inputs used by another calculation remain available. Undo restores the operation and its inputs. The result’s Symbols fields expose factors and entry symbols individually. Enter numbers there to update every matching entry; those values remain editable after closing the panel or reloading.

Vectors, columns, and determinants

Column vector adds an m × 1 matrix; Row vector adds a 1 × n matrix. Both accept symbolic or numeric entries. Matrix opens an m × n editor: choose Rows (m) and Columns (n), then fill its grid. Dimensions range from 1 to 12. Resizing keeps entries at overlapping positions; new cells start at zero. Undo restores removed cells. Use the Orientation selector to transpose a vector without retyping its entries. Scalar multiplier multiplies each entry of a connected vector or matrix by the Scalar factor, which accepts numbers, symbols, and expressions. Connect it before or after the vector or matrix; both orders produce one editable result block with the scalar multiplied into every entry. Add vectors computes A + B for matching row or column vectors in the same reference frame. Subtract vectors computes A − B entry by entry for two row vectors or two column vectors with the same length and reference frame. The result keeps their orientation. Cross product computes A × B for two 3 × 1 vectors. Stack columns places A to the left of B. Both inputs must have the same number of rows. Stack rows places A above B to build a twist (ω; v). Determinant takes a square matrix and simplifies trigonometric squares and angle sums. Select a result and click Stack columns to use it as A.

Click a block on the canvas to open its floating input panel. Drag the panel header to move it; press Enter to finish editing and close it, or close it with ×, Escape, or a click on empty canvas. Use Block name to rename a block; use Rename function in a saved function’s menu to rename it in My blocks.

Templates and examples

Use Templates & examples to start with an empty canvas, a D–H transformation, a product of exponentials, or a screw → matrix → screw example.

The custom_3R templates provide two forward-kinematics constructions. The PoE template contains three screw exponentials followed by the home pose M. The D-H template contains three 4 × 4 matrices; each expands into four D-H operations. Both calculate the pose of tool0 in base_link using the exact custom_3R.urdf. Joint values start unset; enter zero radians for the home pose; the home position is (4.5, 1.25, 1.25) metres. Select a joint block and change q1, q2, or q3 to explore the FK.

Orientation conversions

Rotation ↔ Quaternion, Quaternion ↔ RPY, and RPY ↔ Rotation choose direction from the input shape: a 3 × 3 rotation, a four-component quaternion, or a three-component RPY vector. Use row or column vectors; output vectors are columns. Quaternions use (qw, qx, qy, qz), with the scalar first, and nonzero inputs are normalized. URDF RPY uses Rz(yaw) Ry(pitch) Rx(roll), always in radians. Extracting a quaternion from a matrix or extracting RPY requires numeric input values. At gimbal lock, roll is set to zero and yaw represents the remaining rotation.

Screws and exponentials

Enter the screw as ξ = (ω, v), angular components first. The block shows e[ξ]θ; its Matrix switch reveals the 4 × 4 result. For a unit rotational axis, θ is the rotation angle. For a pure translation (ω = 0), the amount is a displacement and the angle-unit setting has no effect. To screw extracts one principal screw from a numeric rigid transform; its rotational angle is in radians, between 0 and π. Its output is screw coordinates: enter them in an Exponential block to compose that motion.

Combine and reuse

Shift-click (or Ctrl/⌘-click) to select multiple blocks, or drag a rectangle around them. Click Combine to replace a connected chain with one block. Name it ^0T_1 for frame notation or use any label. Save as function stores the selected chain in My blocks; selecting just the final block saves all its upstream operations. Drag a saved function onto the canvas and enter values or symbols for its arguments. A function keeps the angle convention used when it was created. Press Ctrl/⌘ E or use the block’s context menu to expand its operations again.

Python functions

The Python panel shows commented functions for each operation and a callable function for the chain. Its numeric example runs only when the file is executed directly. Download the file to use it in Python, or choose Import Python to bring it back as a reusable block. Playground exports import offline. External NumPy / SymPy functions require a Python runtime download on first use; they must accept scalar parameters and return a symbolic matrix. Edited exports must be re-exported, or have their saved-definition footer removed before external import.

Working on the canvas

The live output starts collapsed to give the canvas more room; use Expand output to inspect it, and Collapse output to return to the canvas. Drag selected blocks by their header, body, or footer. Buttons and ports keep their own actions. Connection lines snap to nearby valid ports; release when the target highlights. Drag empty space to select; hold Space and drag to pan, or use the Pan button. Scroll to zoom. Click Arrange & fit or press Ctrl/⌘ Shift F to lay out all blocks by their connections and fit them on screen. Undo restores the previous layout. Ctrl/⌘ A selects all blocks; Ctrl/⌘ K combines the selection; Ctrl/⌘ E expands a function. Ctrl/⌘ C copies selected blocks, Ctrl/⌘ V pastes, Ctrl/⌘ X cuts, and Ctrl/⌘ D duplicates. Ctrl/⌘ Shift Z or Ctrl/⌘ Y redoes a change. Delete removes the selection; Ctrl/⌘ Z undoes a change. Right-click a connection to disconnect it. Download operations saves an editable JSON file with the graph and My blocks; Upload operations restores it. Download blocks and Upload blocks share reusable operations on their own. Uploads can be undone. Older graph JSON files still open. The current graph and My blocks are saved on this device.

Expressions support +, −, *, /, ^, pi, sin, cos, tan, sqrt, acos, and atan2. Use * explicitly. Function arguments such as sin(pi/2) are always radians; Angle units controls rotation and exponential parameters.

Screw convention: Modern Robotics, §3.3.3.
